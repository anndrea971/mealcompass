# Meal Compass API

REST API for planning weekly meals (CSE 341 final project, Andrea González).
Collections: **users**, **recipes**, **meal plans**, **grocery lists** – full CRUD, validation, GitHub OAuth login.

- API docs: `/api-docs`
- Live site: https://mealcompass.onrender.com/api-docs

## Run locally
1. `npm install`
2. Create a `.env` file (see `.env.example`)
3. `npm start`
4. `npm test` runs the Jest tests
